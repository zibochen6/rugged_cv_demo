# OpenCV is intentionally NOT installed via pip.
#
# JetPack 5.1.3 ships system OpenCV 4.5.4 built from source with NEON/FP16
# optimizations at /usr/lib/python3.8/dist-packages/cv2. We rely on that.
#
# Why we don't pin opencv-python in this file:
#   1. PyPI has no `opencv-python==4.5.4` (the matching version is
#      `4.5.4.60`). An exact `==4.5.4` pin makes pip error out with
#      "No matching distribution found".
#   2. The available wheels (>=4.6) have a broken cv2.gapi.wip.draw.Text
#      module on aarch64 — they raise AttributeError on import.
#   3. System OpenCV (4.5.4, NEON/FP16) is the correct build for Jetson.
#
# If you ever need a different version, install it manually OUTSIDE this
# requirements file (e.g. `pip install opencv-contrib-python-headless==4.5.4.60`)
# and update the comment above.
